# ASU_Book_downloader
Скачивает книги с электронной библиотечной системы АлтГУ

Краткая инструкция:
1. Находите нужную книгу на ЭБС АлтГУ: http://elibrary.asu.ru/xmlui/
2. В коде, в строчке 393 указываете ссылку на выбранную книгу, например http://elibrary.asu.ru/xmlui/bitstream/handle/asu/152/read.7book?sequence=1&isAllowed=y
3. Запускаете скрипт

   Важно!
   Программа не производит оптическое распознавание текста - рекомендуются PDF24 или Wondershare инструменты для OCR
